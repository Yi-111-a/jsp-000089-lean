# JSP-000089

> **Is there a density-zero set of positive integers such that every sufficiently
> dense graph has a cycle with length in that set?**

Erdős and Hajnal's *odd cycle problem*.  Area: graph theory / cycles.  Date
proposed: no later than 1994.

Catalog status: **Solved**.  Historical bounty: $100.  References:
Bondy–Vince, *Cycles modulo k*, Bull. London Math. Soc. 9 (1977) 97–98;
Verstraëte, *Unavoidable cycle lengths in graphs*, J. Graph Theory 49 (2005)
151–167; Liu–Montgomery, *A solution to Erdős and Hajnal's odd cycle problem*,
arXiv:2010.15802 (2020).
